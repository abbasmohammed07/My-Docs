== Introduction

AsciiDoc is a lightweight markup language for authoring notes, articles, documentation, books, and web pages. Many static site generators like Antora, Hugo, and Jekyll (with plugins) support AsciiDoc syntax natively or via extensions.

== Document Header

A typical AsciiDoc document starts with a title preceded by a single equals sign (`=`), followed by author metadata and document attributes.

* `:toc:` automatically generates a table of contents.
* `:icons: font` enables icon rendering for admonitions.

== Basic Text Formatting

You can style text easily using inline punctuation:

* *Bold text* is enclosed in asterisks (`*bold*`).
* _Italic text_ is enclosed in underscores (`_italic_`).
* `Monospace text` is enclosed in backticks (`` `monospace` ``).
* *_Bold and italic_* combines both markers.
