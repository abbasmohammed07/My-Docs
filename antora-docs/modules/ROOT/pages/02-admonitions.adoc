== Admonition Paragraphs

Admonitions draw the reader's attention to important notes, tips, or warnings.

NOTE: Static site generators often require an AsciiDoc processor like Asciidoctor to render these blocks properly.

TIP: Keep your source files modular so you can reuse content across multiple pages.

IMPORTANT: Always validate your front matter YAML before pushing to your repository.

WARNING: Deleting the build output directory manually while the dev server is running may cause temporary errors.

CAUTION: Force pushing (`git push --force`) to the main branch can overwrite deployment history.

.About Static Site Generators
