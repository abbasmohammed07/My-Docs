= Source Code Blocks and Callouts

:source-highlighter: rouge

== Inline Code and Shell Commands

Run `asciidoctor index.adoc` in your terminal to compile a single file into HTML.

== Syntax-Highlighted Source Blocks

AsciiDoc supports language-specific syntax highlighting using the `[source,<language>]` block attribute.

[source,python]
----
def generate_site(pages):
    for page in pages:
        print(f"Building {page}...") # <1>
    return True # <2>
----
<1> Iterates through each source file in the queue.
<2> Signals successful completion of the static build.

== YAML Configuration Example

Below is a sample GitHub Actions workflow snippet for building static documentation:

[source,yaml]
----
name: Deploy Docs
on:
  push:
    branches: [ main ] # <1>
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4 # <2>
      - name: Build Site
        run: echo "Compiling AsciiDoc files..."
----
<1> Triggers the workflow automatically whenever commits are pushed to `main`.
<2> Checks out the repository code onto the runner.
