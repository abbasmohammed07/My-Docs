== Using Document Attributes

Attributes act like variables in your documentation. Defining `:project-name: DocsPortal` in the header lets you reference `{project-name}` anywhere in the text.

* Current Project: *{project-name}*

== Standard Data Table

Tables in AsciiDoc use `|===` delimiters and vertical bars (`|`) to separate cells.

.Static Site Generator Comparison

| Hugo

| Jekyll

|===

== Styled Cells Table

You can apply column specifiers such as `e` (emphasis), `s` (strong), and `m` (monospace) directly in the `cols` attribute.

[cols="1s,2m,3", options="header"]
|===
| File Pattern | Git Command | Purpose

| *.adoc
| git add *.adoc
| Stages standard AsciiDoc files

| *.md
| git add *.md
| Stages Markdown or hybrid AsciiDoc practice files

| .gitignore
| git status
| Verifies ignored build artifacts
|===
