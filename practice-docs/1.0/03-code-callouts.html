YAML Configuration Example

Below is a sample GitHub Actions workflow snippet for building static documentation:

name: Deploy Docs
on:
  push:
    branches: [ main ] (1)
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4 (2)
      - name: Build Site
        run: echo "Compiling AsciiDoc files..."
1 Triggers the workflow automatically whenever commits are pushed to main.
2 Checks out the repository code onto the runner.
