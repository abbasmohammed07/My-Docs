Tables and Document Attributes

Using Document Attributes

Attributes act like variables in your documentation. Defining :project-name: DocsPortal in the header lets you reference DocsPortal anywhere in the text.

  • Current Project: DocsPortal

  • Target Branch: main

  • Recommended Generator: Antora
