Includes, Cross-References, and Git Workflow

Cross-References (xref)

Cross-references link sections within the same document or across different pages in a multi-page site.

  • Internal anchor reference: See Git Push Checklist below.

  • Cross-page reference syntax: Getting Started Guide

Include Directives

The include:: directive pulls content from external files into the current document during compilation.

== Reusable Snippet

Unresolved include directive in modules/ROOT/pages/05-includes-references.adoc - include::partials/disclaimer.adoc[]
Note that the .md file extension is used here per your request, though standard AsciiDoc processors typically look for .adoc files unless configured otherwise.

Git Push Checklist

Follow these steps to push your practice files to GitHub:

  1. Initialize a local repository using git init.

  2. Stage your files with git add ..

  3. Commit your changes with git commit -m "Add AsciiDoc practice files".

  4. Add your remote repository and run git push -u origin main.
